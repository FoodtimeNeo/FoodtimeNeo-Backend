## 执行顺序（一键脚本已串好）

1. 确认分支已合入、服务器 `git pull`、镜像已重新构建（含 V24/V25）。
2. `bash scripts/canteen-refresh/apply-one-click.sh`（需 `DB_URL`/`PGUSER`/`PGPASSWORD`）。
3. 每步输出：备份路径 → 删除计数 → 健康检查通过 → `expect V25` 显示 `25`
   → `placed=49`（有 6-7 张是封面复用或已存在会显示 skipped，正常）
   → 对账 6 项全 PASS。
4. 对账里 `dish_zero_price_todo` 会列出 **13 个 0 元菜品**（菜单写"免费/价格遮挡/未标示"，
   已按 0 入库并在 description 备注原价标注）：**上线前必须向食堂要到价格后改价**，
   否则前台显示 0 元。

## 回滚

任一步失败即停：用 `backups/` 下最近的 `.dump` 执行
`pg_restore -c -d <库名> <文件>`，然后重启应用。图片文件只增不减，
回滚不需要动 uploads。
