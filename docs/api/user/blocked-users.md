# 黑名单列表

登录后通过 `GET /api/v1/users/me/blocks?page=1&size=20` 查询本人主动拉黑的用户。访客账号也可以查看和解除自己的拉黑。分页大小为 1–100，默认 20；按拉黑时间倒序、用户编号排序，返回标准分页结构。

每条记录包含 `id`、`displayName`、`avatarUrl` 和 ISO 8601 格式的 `blockedAt`。不包含邮箱或拉黑自己的其他用户。已停用的目标仍保留在列表，可正常解除。

解除继续使用 `DELETE /api/v1/users/{id}/block`，重复解除幂等，只修改当前用户主动建立的关系。现有拉黑范围保持为阻止双方私信，不自动隐藏社区内容，也不删除会话记录。

Web：个人页 → 黑名单。Android：我的 → 账号 → 黑名单。解除前确认，失败保留记录并可重试；删除末页最后一条后回到有效页。界面重新进入时读取服务器，不在设备长期存储黑名单列表。

`CommunitySafetyIT` 验证真实 HTTP、Cookie 与 CSRF 下的匿名拒绝、账号隔离、分页、停用目标、访客解除及私信拦截。
