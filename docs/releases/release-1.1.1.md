# v1.1.1 发布说明

项目版本更新为1.1.1，稳定构建文件名仍为foodtime-neo-backend.jar。通过dev → main发布PR保留合并历史。

本次集成公告管理及登录展示配套、审核发布者身份与内容时间、超级管理员数据看板，以及开发分支累积的菜单和会话修复。安全修复包含删除固定测试验证码、注册与发码共享限流、邮箱归属验证前隐藏注册状态、图片元数据清理与存储配额、Tomcat/Jackson安全补丁。

部署沿用现有数据库和Redis，Flyway自动处理开发分支累积的迁移；不手工修改数据库版本表。邮件服务必须正确配置，所有环境均需真实验证码。上传目录需保持持久化；默认用户100MiB、总量10GiB、磁盘预留1GiB，可通过环境变量覆盖。详见configuration.md与deployment.md。

发布门禁执行全部单元和数据库集成测试。GitHub CI生成main对应JAR；合并main不会自动部署云端，云端数据库权限和管理端口本次不调整。
