# v1.1.2 发布说明

项目版本为 `1.1.2`，构建文件名仍为 `foodtime-neo-backend.jar`，通过 `dev → main` 发布 PR 保留合并历史。

## 更新范围

- 注册模式开关、官方客户端标识头，以及匿名设备维度的注册限流。
- 邮箱 RCPT 预检及配额语义更新，注册集成测试隔离本地环境。
- 全局在途请求与昂贵路径并发上限。
- 点评、目录简介及请求体长度限制，图片引用格式收紧为小写 UUID。
- 社区帖子 AI 审核阈值调整与传输失败重试。
- 同机反向代理的后端监听地址说明更新。

## 发布要求

在 PostgreSQL 和 Redis 环境运行 `mvnw -B -ntp -Pintegration verify`，核对现有配置与新增开关后部署。本地准备不能替代远程最新状态检查、CI 或实际部署。
