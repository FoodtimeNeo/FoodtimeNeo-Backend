# 帖子浏览量

帖子响应新增非负整数 `viewCount`，历史帖子从 0 开始。客户端只在详情发布日期右侧显示，信息流不显示。

登录后每次进入详情调用 `POST /api/v1/community/posts/{id}/views`，正文为 `{ "clientRequestId": "<uuid>" }`，返回 `{ "viewCount": 1 }`。每次进入生成新编号，同次打开的请求重试复用编号；读取详情 GET、列表刷新、评论和点赞等刷新不自动累计。

仅已审核通过且未删除的帖子累计；作者预览自己的待审核/拒绝帖子返回现有计数，其他用户得到 404。现有 CSRF 与账号状态检查适用。计数和去重记录在同一事务内写入，并发打开不丢计数，相同请求编号不重复计数。

Flyway V43 新增计数列和按帖子/用户/请求编号唯一的去重记录；部署先升级后端，旧客户端可忽略新增字段。
