# 图片缓存协议

- 活跃父级下的目录封面、档口图集和已通过审核的菜品图：`public, max-age=31536000, immutable`。
- 已公开的社区图片、活跃用户的头像：`private, no-cache`，`Vary: Cookie`；每次新读取先校验权限，再使用ETag返回304。
- 暂存、待审、驳回以及删除后作者/管理员可访问的预览：`no-store`，即使带条件头也返回当前200内容。
- 401/403/404不缓存，不允许用旧缓存代替授权。缩略图与原图使用不同ETag。

图片UUID不可变，替换时使用新引用。合法304只读取元数据和可见性，不读取或生成图片正文。档口图集包含首图以外的图片；父级停用后普通用户的新请求被拒绝。既有公开目录缓存不承诺远程撤回已经下载的图片。
