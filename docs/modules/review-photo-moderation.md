# 点评图片与审核

点评可关联一张菜品图片。客户端先提交点评，再在图片投稿中传 `reviewSubmissionId`；服务端校验点评所属用户及菜品，同一点评仅允许一张图片，相同图片的重复提交返回原记录。文字和图片独立审核，图片通过后进入菜品图册；当前已发布点评的对应图片通过后也在点评接口的 `imageUrl` 中返回。

点评图片送 AI 时使用菜品名检查合规性与相关性，不确定时留人工审核；高置信度违规仍可自动驳回。自动通过单独使用 `AI_TRIAGE_REVIEW_PHOTO_APPROVE_ABOVE`，默认 1.01 表示关闭；只有在相关性评测完成后配置 0.99 至 1.0 的阈值才启用。无结论、AI 关闭或故障时图片仍在人工审核队列。普通独立图片投稿保留原有人工通过规则。

上线前应在专用测试集评估相关性误通过和违规漏检，确认阈值、模型和线上审核开关；历史已分诊但仍待审的图片不会因调整阈值而自动补判。
